# Metro Ideas - Endpoint para Vercel

## Variable necesaria en Vercel
Nombre:
OPENAI_API_KEY

Valor:
Tu API key de OpenAI.

NO pongas la clave dentro del HTML ni dentro de ideas.js.

## Endpoint final
Después de desplegar:
https://TU-PROYECTO.vercel.app/api/ideas

Esa URL se pega en "Endpoint HTTPS de IA" dentro de la app Metro.

## Comprobación
Si visitas /api/ideas desde el navegador y responde "Solo se permite POST",
la función está publicada correctamente.
